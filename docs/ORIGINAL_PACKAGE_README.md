# Комплект доработки econtypes

Проверено 09.10.2026. Откройте `ECONTYPES_Audit_and_Methods_20261009.docx`: аудит, приоритетные формулы и полный промпт находятся в одном Word файле. Отдельный `CLAUDE_CODE_PROMPT.txt` удобно целиком скопировать в Claude Code. Подробности путей и покрытий — в `PROJECT_DATA_MAP.md`.

## Рабочая база

`econtypes_research_20261009.sqlite` уже заполнена: 359615 processed contracts, 150234 МСП РБ, 157996 фирм индекса поставщиков разных регионов, население 63 МО в 2022–2025, 1045 ATMO observations и 10000 объявлений/лотов. Проверки базы PASS. Метки/признаки СберИндекса в ней архивные, не новая пересчитанная типология.

Откройте SQLite через Python, sqlite3 или DB Browser for SQLite. Примеры запросов находятся в `example_queries.sql`. Источники с SHA-256 — в `SOURCE_MANIFEST.json`; схема — `SCHEMA.sql`.

## Повторение

Из корня распакованного комплекта:

```bash
python -m pip install -r reproduction/requirements.txt
python reproduction/build_database.py --input-root reproduction --output econtypes_rebuilt.sqlite
python reproduction/audit_project.py
```

Builder создаёт только новый файл. Скрипт аудита записывает новый `reproduction/project_checks.json` и намеренно фиксирует существующие ошибки исходного кода. Пять из двенадцати проверок PASS, семь FAIL. Это контроль функций и экспортов; полный raw ingest, pytest, новая национальная кластеризация и подача не выполнены.

## Следующий запуск

Claude Code должен исправить AVU и временные окна, найти основные raw parquet и подтвердить ИНН→МО, затем пересчитать признаки/рёбра/кластеры и оформить экономические выводы. Snapshot МСП 10.09.2026 не является историческим статусом на дату контракта. ATMO id не приравнивается номеру ЕИС; отсутствующие ИНН и непроверенные межисточниковые дубли требуют отдельной работы.

Исходные пользовательские архивы и документы не изменены. В `reproduction/` находятся их рабочие копии и все входы нового builder. Содержимое больших файлов не урезано. Фактические ограничения доступности и охвата перечислены в аудите.
