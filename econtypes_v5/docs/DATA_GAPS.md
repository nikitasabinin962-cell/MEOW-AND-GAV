# DATA_GAPS — недостающие данные, точный вход, причина и статус

Проверено 09.10.2026 в облачном контейнере. Исходящая сеть к `rosstat.gov.ru`, `02.rosstat.gov.ru`, `sberindex.ru`, `api.sberindex.ru`, `nalog.gov.ru`, `zakupki.gov.ru`, `doi.org` закрыта политикой прокси среды (HTTP 403 на CONNECT, проверено curl). Обходить ограничения не пытались. Google Drive пользователя доступен через MCP — оттуда загружены официальные таблицы Башкортостанстата (см. `external/rosstat_drive/DRIVE_DOWNLOADS.jsonl`).

Статусы: **GAP** — данных нет, расчёт по ним не выполнялся; **PARTIAL** — есть часть/прокси, использование ограничено; **FOUND_NOT_IMPORTED** — источник найден, не загружен; **USED** — закрыто в v5.
