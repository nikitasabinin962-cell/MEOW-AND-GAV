# Методология econtypes v5

Документ описывает формулы, соглашения для вырожденных случаев и границы применимости. Числовые результаты — в `REPORT_v5.md` (каждое число со ссылкой на `run_id`). Код: пакет `econtypes5`.

Охват: **региональный кейс — 63 МО Республики Башкортостан**. Основная типология строится на 62 МО с наблюдаемым блоком СберИндекса; ЗАТО Межгорье выведено отдельно (нет трат СберИндекса — в v4 они были KNN-импутированы, — и нет муниципальных таблиц Росстата). Национальный результат не заявляется: полные входы СберИндекса по всем МО России в доступных каталогах не найдены, сеть к sberindex.ru из среды закрыта политикой прокси. Национальное расширение подготовлено как переносимый конвейер (регион — параметр конфигурации; ядро проверено на синтетике N = 2016, `outputs/SCALE_BENCHMARK.json`).

## 1. Постановка

Узел — МО. Атрибуты — блоки экономических характеристик МО за окно наблюдения. Ребро — математически определённое сходство (атрибутивное) и экономические связи (динамика трат, потоки госзаказа). Кластеризация атрибутированной сети: спектральная и Leiden по совмещённой матрице W.

## 2. Признаки (блоки) и роли

| Блок | Признаки | Формула | Экономическая гипотеза | Режим |
|---|---|---|---|---|

| sber_structure (СберИндекс) | `sber_ilr1…5` | ILR 6 частей (продукты, здоровье, общепит, маркетплейсы, транспорт, прочее) | структура потребления; отделена от уровня | только реконструкция (агрегат 2023–2024) |

| proc_geo | `procgeo_ilr1`, `procgeo_ilr2` | ILR {свой МО, другие МО РБ, вне РБ} по стоимости с известной географией поставщика | локализация госзаказа | оба |
| proc_corp | `proc223_pc_log` | log(1+руб./жителя/год) по 223-ФЗ | присутствие госкомпаний | оба |

| age_structure | `age_ilr1`, `age_ilr2` | ILR {0–14, 15–64, 65+} (ВПН-2020) | демографическая структура | реконструкция; мониторинг — с 31.12.2023 |

Роли не смешиваются: признаки → X; рёбра → W; ICVI оценивают разбиение; co-assignment характеризует устойчивость; внешние показатели (перепись: источники средств к существованию и образование; МСП-специализация 2026; архивные зарплата/занятость/дотации v4; market_access) в обучение v5 не входят.

Преобразования: `supplier_hhi` — логарифм; `proc223_pc_log` — ранговое нормальное (у 4 МО нет заказчиков 223-ФЗ за 2023–2024). Затем робастная стандартизация (медиана, IQR/1,349), клиппинг ±4. Блочный вес λ_b = 1/p_b: каждый блок вносит средний квадрат разности своих координат; X = [√λ_b z_b], поэтому евклидово расстояние по X равно блочному расстоянию. Недоступный в окне показатель исключается из окна целиком (с записью), а не заполняется нулём.

### 2.1 Композиции

clr(p)_j = log p_j − (1/D) Σ_r log p_r; ILR z = Vᵀ log p, V — ортонормированный пивотный базис Эгозкуэ (VᵀV = I, Vᵀ1 = 0); d_A(p,q) = ‖clr p − clr q‖ = ‖ilr p − ilr q‖ (тест изометрии в `tests/test_math_modules.py`). Структурный нуль (часть равна 0 у всех) исключает часть; выборочные нули — мультипликативная замена (δ = 10⁻³ для географии поставщиков); пропуск (NaN) не заменяется. `single_supplier` не входит в географическую композицию (это характеристика процедуры).

Интерпретация ILR (пивотный базис): ilr_k = √(k/(k+1))·(среднее log первых k частей − log (k+1)-й). Например, `sber_ilr2` < 0 означает относительно большую долю общепита; `age_ilr2` < 0 — относительно большую долю 65+.

### 2.2 Сглаженная специализация МСП

p̂_ms = (n_ms + κπ_s)/(n_m + κ), LQ_ms = p̂_ms/π_s; π — доля группы ОКВЭД в РБ (эталон — регион, не Россия). κ выбирается по предсказательному правдоподобию: фирмы каждого МО делятся пополам, p̂ оценивается по половине A, лог-правдоподобие считается на B; сетка κ ∈ {0,…,1000}. Это относительная специализация по числу фирм на снимке 10.09.2026 с адресными кандидатами МО (не ОКТМО) — поэтому только внешний показатель, не признак 2023–2024.

### 2.3 Экономическая сложность и связанность (эксперимент)

Метод отражений Hidalgo–Hausmann: бинарная M (RCA ≥ 1) МО × секция ОКВЭД; ECI — второй собственный вектор M̃ = D⁻¹MU⁻¹Mᵀ, знак нормирован по связи с разнообразием. Плотность связанности ω_ms = Σ_s' M_ms' φ_ss' / Σ_s' φ_ss', φ_ss' = min(P(RCA_s|RCA_s'), P(RCA_s'|RCA_s)). Внешние показатели.

### 2.4 Демографический баланс

ΔN = B − D + M + A. M (чел.) = коэффициент ‱ × средняя численность/10 000; A — остаток (пересмотры, границы, ошибки учёта; не «скрытая миграция»). Таблица `DEMOGRAPHIC_BALANCE.csv` (2023, 2024).

## 3. Рёбра

Self-tuning affinity (Zelnik-Manor & Perona 2004): W_ij = M_ij·exp(−d²_ij/(σ_iσ_j)), σ_i — расстояние до k_scale = 7-го соседа; маска union-kNN (k = 8) или mutual-kNN. Проверки: 0 ≤ k ≤ N−1 (иначе ValueError с объяснением); σ_i = 0 (дубликаты) → наименьшее положительное расстояние, флаг; все строки совпадают → ошибка; NaN-расстояние → ребро невозможно.

Структурные слои по помесячным тратам, **только по месяцам окна** (`timeseries.restrict`): остатки log-трат минус кросс-секционное среднее месяца (траты ≤ 0 → NaN и статус, log(0) не вычисляется); comovement — корреляция приращений по попарно общим месяцам (отрицательные → 0); lead_lag — max_{1≤l≤3} корреляции с лагом; DTW (окно Сакоэ–Чибы 2) по z-нормированным рядам, σ-ядро — медиана положительных расстояний; постоянный ряд не получает рёбер.

Потоки госзаказа: F_ij — руб. от поставщиков МО i заказчикам МО j (оба в РБ, география по `org_geo_resolved`, порог 1 млн руб.); N_ij = F_ij/√(out_i·in_j); S = unit(log(1 + 10³(N + Nᵀ))). Республиканские/федеральные заказчики в Уфе исключены (уровень бюджета из реестрового номера 44-ФЗ).

Совмещённая матрица (baseline v4 сохранён): W = α·S_attr + (1−α)·Σ_ℓ ω_ℓ S_ℓ (α = 0,5; ω v4: 0,35/0,10/0,15/0,40), каждый слой kNN-разрежён (k = 8). SNF (Wang et al. 2014) — сравнительный эксперимент.

**Точная W и визуальная проекция хранятся раздельно** (`run_matrix_edges`: `…|exact` и `…|display_k4`). Все сетевые ICVI считаются по точной W.

География — отдельный контрольный слой (смежность полигонов МО, используется только для пространственных нулевых моделей). market_access содержит географическую информацию и поэтому в признаки v5 не включён (внешний показатель).

## 4. Индексы качества (ICVI)

Пространство признаков X: SW, CH, DB (sklearn), S_Dbw. Сеть W (точная): AVI, AVU, MQ.

E_ab = Σ_{i∈C_a} Σ_{j∈C_b} W_ij, B_a = Σ_{b≠a} E_ab (внутренний вес E_aa при симметричной W учитывает пары дважды).

* **AVI** = mean_a E_aa/(E_aa + B_a) (↑). Кластер без единого ребра исключается из среднего и считается (`n_empty_clusters_isolability`).
* **AVU** = (1/K) Σ_a Σ_{b≠a} U_ab, U_ab = E_ab/(B_a + B_b − E_ab) (↓) — опубликованный Average Unifiability (Biswas & Biswas 2017, ESWA 71:1–17, DOI 10.1016/j.eswa.2016.11.011; Shalileh, Tsyplakova, Antonov, DOI 10.1134/S1064562425700589). Знаменатель 0 возможен лишь при E_ab = 0 и отсутствии внешних связей у обоих кластеров → U_ab := 0, число таких пар возвращается. Свойства, проверенные тестами: три изолированные клики → AVU = 0, AVI = 1; полный граф K кластеров по s узлов → AVU = (K−1)/(2K−3); **при K = 2 AVU ∈ {0, 1}** (B_a = B_b = E_ab) — индекс неинформативен; инвариантность к перестановке меток и нумерации узлов. Прежний показатель v4 d_in/(d_in+d_out) сохранён как `intra_inter_density_ratio` (авторский, ↑) — это не AVU.
* **MQ**: что именно организатор называет MQ, по доступным материалам подтвердить не удалось. Считаются оба значения: `MQ_newman` — взвешенная модулярность Ньюмана Q = (1/2m) Σ_ij [W_ij − γ k_i k_j/2m] δ(c_i,c_j), γ = 1 (чувствительность γ ∈ {0,5; 2} в тестах), неориентированный граф; для несимметричной W — форма Leicht–Newman; `MQ_mancoridis` — Modularization Quality (Mancoridis et al. 1998): (1/K)Σ μ_i/N_i² − Σ_{i<j} ε_ij/(2N_iN_j)/(K(K−1)/2). В отчёте MQ = `MQ_newman`.
* **S_Dbw** (Halkidi & Vazirgiannis 2001): Scat = (1/K)Σ‖σ(v_i)‖/‖σ(S)‖; stdev = (1/K)(Σ‖σ(v_i)‖)^{1/2}; density(u) — число точек C_i∪C_j в шаре радиуса stdev; Dens_bw = (1/(K(K−1))) Σ_{i≠j} density(u_ij)/max(density(v_i), density(v_j)). `density_scope='union'` (оригинал: плотность центроидов по C_i∪C_j) и `'own'` (по собственному кластеру) — для чувствительности. Вырожденные случаи: ‖σ(S)‖ = 0 → NaN; знаменатель 0 и числитель 0 → слагаемое 0; знаменатель 0 и числитель > 0 — отношение не ограничено: `S_Dbw` → NaN (строго), `S_Dbw_floor1` → знаменатель max(den, 1), прежнее поведение v4 (`v4_zero`) поощряло плохое разделение. **Находка:** на восстановленной матрице v4 (p = 32) все 42 слагаемых Dens_bw имеют нулевые плотности (радиус stdev ≈ 0,69 не содержит точек), т. е. S_Dbw v4 = Scat. Радиус убывает как 1/K, поэтому в многомерном X это типичный, а не экзотический случай.

Нормировка: для каждого индекса — нулевое распределение при перестановке меток с теми же размерами (B = 99), z со знаком «больше = лучше», эмпирическое p = (b+1)/(B+1). z не является p-значением и не является универсальной мерой качества; разные пространства признаков не сравниваются по абсолютным значениям — для этого есть перекрёстная оценка всех разметок в общем пространстве C4.

## 5. Выбор K и метода

Сетка K = 2…10, методы: spectral и Leiden (сеть); k-means и Ward (только атрибуты, для сравнения). Правило (зафиксировано в коде до просмотра меток): Pareto-фронт по {SW↑, CH↑, S_Dbw_floor1↓, AVI↑, AVU↓, MQ↑, медиана бутстреп-ARI↑} → минимальный размер ≥ 3 и медиана бутстреп-ARI ≥ 0,5 → максимум среднего ранга z шести индексов. Макроуровень — правило на всей сетке; детальный уровень — то же правило среди K ≥ 5. K = 7 не навязывается. Фронт публикуется целиком (`ICVI_SWEEP.csv`).

## 6. Сравнительная кластеризация

Четыре постановки на одном покрытии (62 МО): C1 — признаки v4 × граф v4 (воспроизведение с исправленными ICVI); C2 — признаки v5 × правило графа v4 (косинус-kNN + архивные слои v4); C3 — признаки v4 × граф v5 (self-tuning + слои v5 по окнам); C4 — признаки v5 × граф v5. Для каждой — полная сетка методов × K; плюс абляция C4 (исключение и последовательное добавление блоков, исключение слоёв, α, k, k_scale, mutual-kNN, правила ребра при равной плотности, SNF, строгая география заказчиков). Изменения разметки — ARI и VI (Meilă 2007).

## 7. Динамика

Окно квартала t — скользящие 4 квартала до t (warm-up 2023Q1–Q3). Режимы: **мониторинг** (только данные с датой доступности ≤ конца окна; демография с консервативными лагами публикации, перепись — с 31.12.2023, структура трат — недоступна) и **реконструкция** (может использовать позднюю информацию; такие признаки помечены `hindsight=1`). Эволюционное сглаживание W̃_t = (1−β)W_t + βW̃_{t−1} по общим узлам; β ∈ {0; 0,3; 0,5; 0,7; 0,9}. Метки выравниваются венгерским алгоритмом по пересечениям с предыдущим кварталом; T_ab = |C_a∩C_b|/|C_a|, J_ab — Жаккар; события: continuation, split (≥ 2 преемника с T ≥ 0,3 и ≥ 2 МО), merge, birth, death; приход/выход МО — отдельно; сдвиг профиля выровненного типа — L2 медиан.

**Тест отсутствия будущей информации** (исполняется в каждом прогоне): траты после 2023-12 умножаются на случайные коэффициенты, суммы контрактов после 2023Q4 искажаются, численность 2024–2025 меняется; в режиме мониторинга признаки, W и метки для всех t ≤ 2023Q4 должны совпасть побитно (`LEAKAGE_TEST.json`); в реконструкции изменения ожидаемы и фиксируются.

## 8. Неопределённость

P_ij = Σ_b O_ij 1(c_i = c_j)/Σ_b O_ij по совместно наблюдавшимся парам (иначе NaN); устойчивость узла — среднее P_ij по своему типу без самопары. Схемы: (1) подвыборка 80% узлов, B = 200; (2) бутстреп временных блоков месяцев (moving block, длина 3, B = 100) с перестроением слоёв; (3) перестроение признаков/сети (k ∈ 6…10, k_scale ∈ 5…9, α ∈ {0,4; 0,5; 0,6}, шум 5% sd признаков; B = 100). Частоты — воспроизводимость процедуры, не апостериорная вероятность истинного типа.

## 9. Связи и проверка независимыми показателями

Pearson (линейные связи после преобразований) и Spearman; n, пропуски, асимптотическое p (scipy), перестановочное двустороннее p = (b+1)/(B+1) с B = 9999 (векторизовано; сверено с `scipy.stats.permutation_test` в тестах), 95% bootstrap-CI; поправки BH и BY (`scipy.stats.false_discovery_control`) внутри семейства «признак × внешний показатель × метод»; e-BH (Wang & Ramdas 2022) с калибратором κ = 1/2 — чувствительность при произвольной зависимости. Пространственная зависимость: нулевая модель Moran spectral randomization (Wagner & Dray 2015) по смежности полигонов — суррогаты сохраняют I Морана. Контроль масштаба — частная корреляция по остаткам на log численности; влияние выброса — без Уфы. «Устойчивая» связь: q_BY < 0,05, пространственный q_BH < 0,05, знак сохраняется при контроле масштаба и без Уфы, CI не накрывает 0. Панель: between (средние МО) и within (отклонения от средних МО) с кластерным бутстрепом по МО. Номера кластеров — номинальная шкала: связь типа с внешним показателем — Kruskal–Wallis H, ε², перестановочное и пространственное p.

### 9.1 Проверка вне периода обучения

Типы 2023–2024 предсказываются по блокам госзаказа 44-ФЗ (`proc_budget` + `proc_geo`) за 2025 и 2026 (январь–сентябрь) методом ближайшего центроида; стандартизация — медианы/IQR 2023–2024. Та же процедура на обучающем периоде даёт потолок точности. Нуль — перестановка предсказанных меток при фиксированных референтных, p = (b+1)/(B+1), B = 9 999. Блок 223-ФЗ исключён: покрытие выгрузки 223-ФЗ в 2025 г. обрывается (1 340 записей против 35 631 в 2023 г.; `DATA_GAPS.md`, п. 25). Это проверка воспроизводимости разметки по одному блоку, а не доказательство экономической истинности типов. Предсказания по МО — `HOLDOUT_PREDICTIONS.csv`.

### 9.2 Имена и паспорта типов

Имя типа — два наиболее отличительных признака: наибольшие |разности медиан робастных z| между членами типа и остальными МО; якорные МО не используются. Для знаковых показателей (изменение населения, естественный и миграционный прирост) формулировка учитывает знак медианы типа: при отрицательной медиане и положительной разности тип описывается как «меньший миграционный отток», а не «приток». Паспорт содержит медианы в исходных единицах, внешние показатели, специализацию МСП, устойчивость членства и пограничные МО (устойчивость < 0,5).

## 10. Привязка организаций к МО

Проверенного ИНН/КПП → ОКТМО с датой действия нет. Уровни доказательности (`org_geo_resolved.quality`): `name_and_tax_office_agree` (название явно указывает МО и совпадает с кодом налогового органа из КПП), `name_only`, `name_tax_office_conflict`, `tax_office_hypothesis` (код налогового органа КПП → МО по эмпирической таблице; точность оценена leave-one-out на организациях с явным МО в названии), `msp_registry_address_2026` (адрес из реестра МСП на снимок), `outside_region`, `unresolved`. Первые 4 цифры ИНН — только анализ чувствительности. Основной вариант признаков — «inclusive» (название + код налогового органа), чувствительность — «strict» (только название).

## 11. Воспроизводимость

`run_id` = время + хеш конфигурации; в манифесте прогона — хеш кода, хеш реестра источников, seed, тайминги, пиковая память, предупреждения (без глобального подавления). Одна команда: `bash scripts/run_all.sh`. Зависимости — `requirements.lock`.
