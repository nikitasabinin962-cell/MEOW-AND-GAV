# Проверка econtypes относительно задачи конкурса

Проверено 09.10.2026 по обоим архивам, переданному HTML, документам методов и найденным файлам данных. Предмет работы — подготовка исправлений и новой рабочей базы для Claude Code. Новая итоговая кластеризация и конкурсная подача в этой работе не выполнялись.

## Основной вывод

Проект уже содержит расчётный пакет, экономические признаки, несколько слоёв сети, сравнение методов, квартальную динамику, отчёт и автономную визуализацию. Наиболее важны исправление AVU, согласование исторических окон, проверка муниципальной географии организаций и точное происхождение новых данных. Добавление нейросетей до этих исправлений не закрывает пробелы критериев.

Эта таблица не является присвоением баллов жюри. Региональный анализ 63 МО не равен выявленной структуре всей России; национальное расширение требует собственного запуска.

## Подтверждённые замечания к коду

1. `econtypes/icvi.py`: `avi_avu` реализует AVU как отношение внутрикластерной и внешней плотности; `HIGHER_BETTER` максимизирует его. Проверенная статья DOI 10.1134/S1064562425700589 задаёт другой AVU с направлением вниз. Тест трёх изолированных clique даёт старый AVU=1 при reference AVU=0. Исправление влияет на подбор K и агрегированную оценку моделей.
2. `pipeline.py`: quarterly `lq=dict(struct_layers)` переиспользует comovement/lead_lag/DTW по всем месяцам 2023–2024. Это несовместимо с интерпретацией каждого снимка как знания только до его даты. Ретроспективный контекст допускается, если честно обозначен; для заявленного мониторинга нужен отдельный запуск без будущих периодов.
3. `features.py` и `mo_directory.py`: география поставщиков/заказчиков по первым цифрам ИНН — слабая гипотеза, не подтверждённый ОКТМО. Поэтому статус «реальные муниципальные потоки» требует проверки адресов и эффективных дат.
4. `pipeline.py`: Wf для кластеризации объединяет слои и содержит 1065 положительных рёбер. Экспорт fused ещё раз kNN-разрежён до 310 рёбер. Разница намеренно заложена в код, но для воспроизводимости нужно отдельно сохранять полную матрицу. Если пересчитать MQ на display-edges, результат меняется примерно с 0.2441 на 0.3725; это не округление.
5. `validate.py`, `pipeline.py`: finite permutation p-values вычисляются долей симуляций и могут быть нулевыми. Нужно `(b+1)/(B+1)`. Нулевая гипотеза для классификационного совпадения должна учитывать actual predicted labels. Нельзя трактовать RF, обученный на собственных cluster labels, как независимую экономическую валидацию.
6. `networks.py`: DTW constant rows вызывает NaN, log(0) даёт нечисловые residuals, k>N порождает IndexError. На реальных missing/zero данных нужны правила и прозрачные диагностические статусы.
7. `icvi.py`: S_Dbw denominator использует union двух кластеров. Это нужно сверить с выбранным первоисточником, не переименовывая варианты одного индекса без объяснения. Тест всей реализации S_Dbw против независимой канонической версии ещё не выполнен.
8. `config.yaml`: final_method задан заранее, min_cluster_size=7 и диапазон K=3…8 ограничивают выбор. Это допустимые гиперпараметры только с содержательным обоснованием и чувствительностью, не требование конкурса. Якорные названия типов требуют проверки новых профилей.
9. `prepare.py`: missing procurement/OKPD features заполняются нулём. Ноль может означать отсутствие закупок либо отсутствие наблюдений; нужны coverage masks. Состав долей и географические категории поставщиков требуют полного остатка/unknown.
10. `build.py` фронтенда: жёсткий hash D.json защищает старую версию, но мешает обновлению без version manifest. Build time не должен изображать свежесть статистики. SHA старого файла сохраняется, новая версия получает свой hash и периоды.

## Что удалось воспроизвести

Из `features_raw_2023_2024.csv` восстановлены преобразования, KNN-imputation, RobustScaler и clipping, из рёбер всех базовых слоёв — полная fusion W. Это воспроизведение сохранённого результата, а не повторный ingest исходных СберИндекс/ЕИС.

| Метрика | Получено |
|---|---:|
| SW | 0.0510323760 |
| CH | 5.8515825222 |
| DB | 2.0749474630 |
| S_Dbw старой реализации | 0.7181470393 |
| MQ как modularity Q | 0.2441383345 |
| AVI | 0.3720891682 |
| Старый авторский «AVU» | 0.8017049076 |
| AVU по опубликованной формуле | 0.5358312305 |

Первые четыре совпали с экспортом практически до машинной точности, сетевые показатели — с расхождением менее 4×10⁻⁷ из-за округлённых рёбер. Слабый SW отражает перекрывающиеся атрибутивные профили; это не запрещает сетевую типологию, но требует аккуратного объяснения и неопределённости.

## Строгие проверки которые действительно выполнены

`PROJECT_CHECKS.json`: 12 целевых проверок, 5 PASS и 7 FAIL. PASS: размеры/finite baseline, воспроизведение индексов, stress kNN на N=2016, инвариантность выравнивания к переименованию меток, корректное отклонение K=N библиотекой. FAIL: AVU formula/direction, AVU disconnected case, finite permutation zero p, constant DTW, log-zero, k>N error type, повторное использование full-horizon layers.

Последний тест утечки является анализом исходного кода, не исполненным экспериментом изменения будущего. Full pytest suite и новый national pipeline не запускались: в окружении отсутствовали их зависимости и основные raw parquet. Эти пункты переданы Claude Code, не помечены зелёными.

Реальная проверка kNN: N=2016, k=8, dense matrix 32514048 байт, 9654 ребра после симметризации; около 0.17 секунды в данном окружении. Этот результат не переносится на all-pairs DTW, полный ingest и браузерную 3D визуализацию.

## Новые данные и АТМО

В новом SQLite есть весь обработанный региональный CSV МСП, все восемь ранее очищенных частей контрактов, региональное население 2022–2025, 1045 observations ATMO и 10000 notices XLSX. Данные отделены от старой разметки. Наличие записи в базе не превращает upstream-неопределённую identity в подтверждённую.

АТМО 223-ФЗ: 910 строк, 908 API id, два точных повторения raw. Сумма после исключения повторов 149559875.64 руб.; до исключения — 149731148.24 руб. Фактические даты 16.01.2025–08.10.2026. Во всех нормализованных строках предмет заменён на название закона; восстановлен `raw.purchase_object`. ИНН отсутствуют, проверка электронных подписей не выполнялась. Это наблюдения публичного реестра, не доказательство оплаты или исполнения.

АТМО 44-ФЗ: проверены 135 строк одной части. В raw есть даты заключения и предмет, а normalized их теряет; 74 active, 58 fulfilled, 3 terminated. Сумма всех наблюдаемых цен 3602584.41 руб. не равна фактическим расходам и включает разные статусы. Выборка опубликована под фильтром 2024-12, договорные даты 10.01.2024–11.12.2024. Полные новые выгрузки 44-ФЗ ещё не обработаны: манифест 493912 — заявление сборщика, отдельный незавершённый пункт проверки.

СБИС/ЕИС: 359615 строк из 8 canonical CSV импортированы полностью. По `identity_basis` 357156 имеют подтверждённое upstream-основание и 2459 только exact representation. Это не независимая новая проверка всех исходных карточек. Валюта и financial_status сохранены: известные RUB-суммы 1263174213398.89 руб. совпадают с прежним отчётом; иностранные валюты и конфликты не добавлены к рублям.

МСП РБ: 150234 unique INNs, все checksum valid; micro 145411, small 4410, medium 413. Headcount отсутствует у 111477 записей. Текст адреса даёт 60089 district candidates, 90144 city candidates и 1 конфликт; verified ОКТМО ещё нет. Индекс контрагентов из других регионов необходим для общероссийского join поставщиков; региональный-only join даёт 129014 найденных контрактов. Индекс релевантных фирм из разных регионов содержит 157996 строк и даёт 173892 найденных контракта, 103660 не найденных, 82063 без ИНН поставщика. Он не равен всему национальному реестру МСП. Итоговая проверка индекса и полного join записана в `DATABASE_CHECKS.json` и SQL quality tables.
