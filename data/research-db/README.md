# Полная исходная исследовательская база

`econtypes_research_20261009.sqlite.gz` — обычный файл Git, загрузка через
Git LFS не требуется. Архив: 83 174 058 байт; SQLite: 538 398 720 байт.
Исходная база не пересчитывалась и не изменялась.

Контрольные суммы, количество строк по таблицам и результат проверки
целостности приведены в [MANIFEST.json](MANIFEST.json).

После скачивания всего проекта распакуйте базу из корня проекта:

```text
python data/research-db/restore.py
```

Скрипт использует только стандартную библиотеку Python 3.11+, проверяет
SHA-256 архива и восстановленной базы. Готовая база появится рядом с архивом.
Существующий отличающийся файл не перезаписывается.

Это исследовательская база исходного комплекта v4: контракты, МСП,
население, ATMO и архивные производные данные. Она отличается от базы
результатов v5. Отсутствующие первичные источники не восстановлены.

Для просмотра панели SQLite распаковывать не требуется: данные интерфейса
уже встроены в `index.html`.
