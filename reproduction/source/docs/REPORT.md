## Общая система

- **Токены** взяты из ТЗ и доведены по контрасту: тёмная тема графит `#10171D`/`#19242D`, светлая тема жемчужно-серая `#F2F5F6`/`#FBFCFD`. Тёмная тема собрана отдельно, а не инверсией светлой.
- **Шрифты:** Golos Text (кириллица) и JetBrains Mono для чисел; везде `tabular-nums`.
- **Раздельные семантики** с собственными цветами:
  - 7 типов (приглушённые на карте, насыщеннее в маркерах);
  - корреляция: синий ↔ охра, симметрично около 0;
  - риск ◆, возможность ●, ориентир ■ — маркер и подпись, без заливки карточки;
  - сетевые слои по семействам: госзаказ — бронза, итоговая сеть — жемчуг, сходство — серо-голубой;
  - выбор — жемчужный контур;
  - нет данных — штриховка и «н/д», а не 0.
- **Тема:** переключатель «Как в системе / Светлая / Тёмная», выбор запоминается. Смена темы перекрашивает полигоны Leaflet, canvas-потоки, матрицу и все SVG-графики.
- **Навигация:** 7 вкладок с прежними названиями, стрелки клавиатуры, адрес `#map` и т.п. Состояние сравнения, выбранного МО и фильтров сохраняется между вкладками.
- **Шапка:** регион, период данных, дата сборки, авторы, ссылки «О проекте · Отчёт (PDF) · Код». У PDF подсказка: «в рамках редизайна не пересоздавался».
- **Компоненты** имеют различимые состояния hover/focus/selected/disabled: кнопки, сегментные переключатели, select/search, slider, чипы, теги, tooltip, раскрытия, таблицы с липкой шапкой, легенды, инспекторы, пустые состояния.
- `prefers-reduced-motion` отключает анимацию связей, морфинг и плавную прокрутку.

## По страницам: композиция → сохранённая аналитика → проверено

### 1. Выводы и рекомендации
- **Композиция.** Главный вывод (1-й абзац `D.summary`) — крупный лид; остальные 3 абзаца идут колонками; справа — мини-оглавление со счётчиками. 8 фактов собраны в сетку 4×2 с номерами, числа в тексте выделены моноширинным (текст не меняется). Темы действий разбиты на три колонки: Риски / Возможности / Переходные случаи. У каждой темы маркер, счётчик, полоса «доля МО региона», смысл, чипы всех районов («+ ещё N») и действия «Отфильтровать список» / «Показать группу на карте». Список МО — плотные строки: имя, тип, главная тема с доказательством, теги. Раскрытие показывает полную сводку, все рекомендации (evidence + action) и отклонения от типа. Над списком — липкая панель фильтров.
- **Сохранено.** `D.summary`, 8 `D.findings` (у факта 5 — переход к 5 центрам), все темы и все районы в них, пресеты, свои условия над процентилями с оператором «и» и ≥/≤, поиск, фильтры по типу и теме, счётчик «показано X из 63», переход на карту, добавление в сравнение.
- **Проверено.** 8 фактов; все районы каждой темы; поиск; пустое состояние со сбросом; свои условия «активность ≥ 50 и бюджетная зависимость ≥ 60» (число строк = расчёт по `D`); раскрытие с полной сводкой; добавление в сравнение; «Показать на карте» передаёт точный набор МО.

### 2. Карта и сеть
- **Композиция.** Панель управления в две строки сгруппирована: раскраска / связи и порог / флажки / поиск. Карта и инспектор шириной 430 px. Поверх карты — стеклянные панели: переключатель «Карта / Значения / Сравнить потоки» и сворачиваемая легенда (тип или шкала, слой связей с единицей и направлением, «показано X из Y», строка о миграции).
- **Геометрия.** Заливка и тонкий контур — один SVG-путь Leaflet. Жемчужная вуаль, внутреннее свечение (размытый штрих, обрезанный clip-path по тому же пути, `evenodd` для отверстий) и чёткий контур — копии того же атрибута `d`. `MutationObserver` синхронизирует их при каждом изменении: zoom, pan, resize. Разойтись с заливкой они не могут. Ширина свечения считается по экранной «толщине» района (4·площадь/периметр), поэтому малые МО не заливаются светом. Вуаль 0,14 в тёмной теме и 0,07 в светлой; появляется за 0,28 с и дальше статична. Под полигонами лежит подложка из той же геометрии с широким штрихом цвета внешней границы: это внешний контур региона и сглаживание стыков. Территория не дорисовывается.
- **Потоки.** Отдельный canvas-слой в панели Leaflet рисует квадратичные дуги, приподнятые над плоскостью. В обзоре высота ≤ 18 px, у связей выбранного МО — до 64 px с пунктирной тенью на земле. Ширина и прозрачность передают силу; слабые рисуются позади, смешивание обычное, не аддитивное. Встречные направления расходятся в разные стороны, у хабов лёгкий веер. Двигается только короткий световой участок, только у направленных слоёв (`flow_rub`, `lead_lag`), только source → target. Без выбора анимируются ≤ 40 сильнейших дуг, при выборе — только связи МО. Цикл один и останавливается при скрытой вкладке, карте вне экрана, режиме «Значения», reduced motion и выключенном флажке «анимация связей». Наведение (допуск 7 px, без утолщения) показывает tooltip; нажатие закрепляет инспектор связи: оба МО, направление или «ненаправленная», слой, значение, единица, период.
- **Режимы.** «Значения» — упорядоченные полосы текущего показателя по всем МО; МО без значения перечислены отдельно. «Сравнить потоки» — две синхронные карты: сеть связей и миграционный прирост с подписью «показатель района, не маршруты».
- **Сохранено.** Все режимы раскраски (тип, макротип, тип по кварталам со слайдером, устойчивость, 13 индексов, 32 признака). Все 9 слоёв и «нет». Слайдер «Сила ≥» с прежней семантикой перцентиля. Расширение каркаса связями выбранного МО. Флажки: «только связи выбранного МО», OSM, «пограничные — пунктиром». Группа по условиям, поиск, полная карточка МО: тип, макротип, население, устойчивость, типичность, сводка, все рекомендации, отклонения, вероятности типа, сравнение с ориентиром, 13 индексов с раскрываемым расчётом, таблица «МО / медиана типа / медиана региона», тип по кварталам, траты по месяцам (разрывы не интерполируются), аналоги, сильнейшие связи + «показать все N».
- **Проверено.** Выбор Уфы, малого МО (г. Агидель) и района с отверстиями (Ишимбайский): путь свечения равен пути заливки после глубокого zoom (10), pan и resize до 1024×768. Порог 0% → все 310 рёбер `fused`, 95% → меньше. `flow_rub`: анимация идёт; tooltip содержит «→», «млн ₽», «поставщик → заказчик»; нажатие открывает инспектор связи. Выключение анимации останавливает цикл; ненаправленный слой не анимируется. Квартальный режим, группа по условиям, «Значения», «Сравнить потоки», отсутствие OD-миграции в легенде. Смена темы перекрашивает полигоны.

## Фактические ограничения
1. **3D.** Дуги «приподняты» в экранной псевдоперспективе на canvas поверх Leaflet; это не WebGL-камера с наклоном. Полноценная сцена (MapLibre + deck.gl `ArcLayer`) не внедрялась: она требует внешних WebGL-библиотек, а исходный файл работает офлайн. Высота дуги только разводит пути; это написано в легенде.
2. **Библиотеки.** ECharts не подключался. Морфинг «МО ↔ По типам», Bubble Plot, матрица, dot plot и дерево написаны на SVG/HTML с теми же приёмами. Внешних зависимостей кроме шрифтов нет.
3. **Миграция.** Межмуниципальной OD-матрицы в данных нет. Маршруты не рисуются, миграция показана как показатель района. Демонстрационных маршрутов в рабочем файле нет.
4. **Направление `flow_rub`.** Слой подписан «поставщик → заказчик», а формула индекса хаба говорит о сети «заказчик → поставщик». Направления не менялись; расхождение вынесено на вкладку «Как это работает» и требует сверки с кодом этапа `metrics`.
5. **Шаблон pipeline.** Перенести в `econtypes/templates/dashboard.html`: содержимое `src/template.html`, `src/styles.css` и `src/js/*.js` (в порядке номеров). Маркер данных `__D__` соответствует месту `const D = …` в шаблоне. `build.py` показывает, как собрать файл.
6. **Скриншоты.** Только из headless Chromium 1194 (`docs/screenshots`). В Safari и Firefox файл вручную не проверялся.
7. **PDF-отчёт** не пересоздавался.
