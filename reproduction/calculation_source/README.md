# econtypes — экономические типы муниципалитетов по атрибутированной динамической сети

Решение номинации **«Кластеризация»** онлайн-конкурса СберИндекса.

**Авторы:** Гилязетдинова Елена Рубиновна, Давлетова Лиана Фаритовна. Программа загружает данные в базу,
строит сеть муниципальных образований, находит типы локальных экономик методами машинного обучения,
считает индексы и корреляции, формирует выводы и рекомендации по каждому МО и собирает интерактивный
дашборд с картой. Пример — Республика Башкортостан, 63 МО (54 района и 9 городских округов), 2023–2024 гг.

* **Узлы** — МО. **Атрибуты** (32 признака): как тратят жители (СберИндекс), как тратит государство
  (153 тыс. контрактов 44-ФЗ из ЕИС), демография, дотации, занятость и зарплаты (БД ПМО Росстата), плотность.
* **Рёбра** — пять слоёв: синхронность трат, опережение на 1–3 мес., сходство формы рядов (DTW),
  **денежные потоки госзаказа между МО**, сходство признаков; расстояние по дорогам — для проверки.
* **Результат** — 7 типов (и 3 макротипа), 13 индексов для каждого МО, значимые связи, карточки МО с рекомендациями.

## Установка и запуск

```bash
git clone <репозиторий> && cd econtypes
pip install -e .              # ставит команду econtypes; для PostgreSQL: pip install -e ".[postgres]"
sudo apt install poppler-utils  # pdftotext — для PDF Башкортостанстата
econtypes all                 # ≈ 3 мин: файлы → база → модель → проверка → индексы → ML → связи → выводы → дашборд
```

Откройте `outputs/dashboard.html` в браузере — это карта с приближением, рёбрами сети и карточками МО.
Чтобы обновить сайт проекта в `docs/` после пересчёта: `bash scripts/update_site.sh`.

## Команды

| Команда | Что делает | Пишет в базу |
|---|---|---|
| `econtypes ingest` | читает файлы из `config.yaml` (CSV ЕИС, parquet СберИндекса, PDF, DOCX, Word-паспорта БД ПМО) | `raw_*` |
| `econtypes add-eis ПАПКА ГОД [--holdout]` | склеивает новую выгрузку ЕИС, проверяет пропущенные страницы, добавляет в конфиг | — |
| `econtypes run` | признаки, сети, 7 методов кластеризации × k, ICVI, бутстреп, динамика по кварталам | `res_clusters`, `res_edges`, `res_icvi`, … |
| `econtypes validate` | узнаются ли типы на закупках следующих лет (2025, 2026) | `outputs/validation_holdout.json` |
| `econtypes metrics` | 13 индексов МО и отличия от своего типа | `res_metrics` |
| `econtypes explain` | случайный лес на метках типов: точность, важность признаков, аналоги | `res_ml_*`, `res_analogs` |
| `econtypes correlate` | Спирмен + FDR, частные корреляции, лаги, различия между типами | `res_correlations`, `res_partial_corr`, `res_lag_corr*` |
| `econtypes report` | выводы по региону и карточки МО с рекомендациями | `res_mo_report`, `outputs/conclusions.md`, `outputs/mo_reports.md` |
| `econtypes geo` | границы МО (geoBoundaries / OpenStreetMap) | `data/geo/*.geojson` |
| `econtypes dashboard` | интерактивный дашборд с картой | `outputs/dashboard.html` |
| `econtypes figures`, `landing` | статичные рисунки и лендинг | `outputs/figures`, `outputs/landing` |
| `econtypes db`, `econtypes sql "SELECT …"` | состав базы и произвольные запросы | — |

Флаги: `--config путь.yaml`, `--db строка_подключения`.

## База данных

По умолчанию — файл SQLite `data/econtypes.db`, ничего настраивать не нужно. Любая другая база, которую
понимает SQLAlchemy:

```bash
econtypes --db postgresql+psycopg2://user:pass@host/econ all
econtypes sql "SELECT mo, cluster_name, localization_pct, budget_dep_pct FROM res_metrics ORDER BY budget_dep_pct DESC LIMIT 10"
```

Слой `raw_*` — очищенные исходные данные, слой `res_*` — результаты. BI-системы и Excel могут
подключаться к базе напрямую.

## Типовая модель: другие регионы

Башкортостан — пример применения. Модель типовая: всё региональное собрано в разделе `region` конфига
(название, код субъекта в ИНН, региональный центр, особые МО) и в модуле `econtypes/region.py`; остальной код
не привязан к конкретным МО. Основные данные федеральные: набор СберИндекса покрывает ≈2 100 МО всей России,
ЕИС, БД ПМО и границы МО есть для всех регионов. Региональные источники (демография, законы о бюджете)
необязательны. Типы без «якорных» МО получают автоматические названия по профилю.

Запуск для другого субъекта — пять шагов, описаны в [docs/SCALING.md](docs/SCALING.md); образец конфига —
[`config/region_template.yaml`](config/region_template.yaml):

```bash
econtypes --config config/tatarstan.yaml geo
econtypes --config config/tatarstan.yaml all
```

Перенос проверяется автотестом `tests/test_region.py`.

## Новые данные

* **Новый год закупок:** выгрузить реестр контрактов ЕИС в CSV, затем `econtypes add-eis папка 2027 && econtypes all`.
* **Новый показатель:** положить файл в `data/raw`, прописать в `config.yaml`, добавить функцию чтения по
  образцу `econtypes/external.py`. Признак автоматически войдёт в модель, корреляции, отчёт и дашборд.
* **Автоматический пересчёт на GitHub:** `.github/workflows/rebuild.yml` запускает `econtypes all`,
  коммитит результаты и обновляет сайт проекта.

Список открытых источников, которые стоит подключить, и где их взять — в [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md).

## Методология

Подробно — в [docs/METHODOLOGY.md](docs/METHODOLOGY.md). Кратко:

1. **Привязка к МО.** Контракты — по первым 4 цифрам ИНН (код налоговой инспекции), таблица «код → МО»
   выводится из данных. Республиканские заказчики в Уфе исключены из признаков Уфы. id СберИндекса
   сопоставлены с названиями по совпадению рядов.
2. **Сеть.** Каждый слой прорежен до 8 соседей; $W = \alpha S_{attr} + (1-\alpha)\sum_l w_l S_l$, α = 0,5,
   веса: синхронность 0,35, опережение 0,10, DTW 0,15, потоки госзаказа 0,40.
3. **Кластеризация.** 7 методов (k-means, Уорд, GMM по признакам; спектральная и Louvain по связям и по
   совмещённой сети) × k = 3…8. Качество — 7 ICVI (SW, CH, DB, S_Dbw, MQ, AVI, AVU), каждый нормирован
   на 40 случайных перестановок меток. k выбирается автоматически (кластеры не меньше 7 МО).
4. **Динамика.** Эволюционная спектральная кластеризация по скользящим 4 кварталам (β = 0,5).
5. **Проверка.** Бутстреп, территориальная связность, отнесение МО по закупкам 2025–2026 гг.
6. **ML-объяснение.** Случайный лес на метках типов (leave-one-out), важность признаков, аналоги в графе.
7. **Индексы, связи, рекомендации.** 13 индексов в процентилях; корреляции Спирмена с поправкой
   Бенджамини–Хохберга и частные корреляции; правила рекомендаций с числовым обоснованием.

## Результаты (Башкортостан, 2023–2024)

| | |
|---|---|
| Лучший метод | спектральная кластеризация совмещённой сети: средний нормированный ICVI 16,1 против 15,6 у Louvain на той же сети, 14,7 у k-means по признакам и 7,8–9,8 у методов «только связи» |
| Число типов | k = 7 выбран автоматически; макроуровень k = 3 |
| Устойчивость (бутстреп 80% МО × 200) | ARI = 0,61 для 7 типов, 0,78 для 3 макротипов |
| Территориальная связность | 214 км внутри типа против 277 км у случайного разбиения, p < 0,001 (география в модель не входила) |
| Проверка на новых данных | по закупкам 2025 и 2026 гг. тип узнаётся в 30% и 35% случаев при случайном уровне 15% (p ≤ 0,002) |
| ML | случайный лес восстанавливает тип не виденного МО в 75% случаев (базовая линия 22%) |
| Связи | из 990 пар признаков и индексов значимы после FDR 284, устойчивы к контролю размера и урбанизации 66 |
| Внешняя проверка | типы различаются по трансфертам из бюджета РБ на жителя (p < 0,001; в 1,8 раза между крайними типами) и по рейтингу открытости бюджетных данных (p = 0,009); индекс бюджетной зависимости связан с трансфертами ρ = 0,83 (2025 г., вне модели, — 0,82) |
| Роль атрибутов и связей | только признаки (α = 1) → ARI 0,48 с итогом; только связи (α = 0) → 0,32 |

## Ограничения

* Госзаказ описывает бюджетный сектор, траты СберИндекса — безналичные операции.
* Префикс ИНН показывает место регистрации поставщика, а не место работы.
* 24 месяца трат дают слабые лаговые связи, поэтому вес этого слоя 0,1.
* ЗАТО Межгорье нет в данных СберИндекса: траты восстановлены kNN-импутацией.
* 63 наблюдения: корреляции описывают связи, а не причинность.
* События (открытие и закрытие предприятий, инвестпроекты) в модель не входят; новости региональных СМИ —
  возможный ранний индикатор смены типа, если выгружать их с фиксированной датой.
