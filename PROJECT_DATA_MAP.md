## Чего пока нет для полного перерасчёта

Основных raw parquet СберИндекса и ЕИС из `config/config.yaml` в расчётном архиве нет. Нет проверенного исторического ИНН/КПП→ОКТМО и истории МСП по годам. В новых ATMO JSON нет ИНН. В canonical CSV нет таблицы товарных позиций с подтверждёнными ОКПД2. Данные населения по возрастам из переписи найдены в каталоге, но не импортированы. Это конкретные пробелы; новая база уже позволяет анализ населения, SQL join МСП и контрактов, проверку происхождения и подготовку нового ingest.

## Повторение

Из корня пакета: `python reproduction/build_database.py --input-root reproduction --output econtypes_rebuilt.sqlite`. Существующий файл скрипт не заменяет. Для повторения проверок функций: `python reproduction/audit_project.py`. Пакеты для этих команд указаны в `reproduction/requirements.txt`; зависимости полного проекта находятся также в исходном `calculation_source/pyproject.toml`.

Все файлы, прочитанные для новой базы, находятся в `reproduction/materials/`; названия и SHA-256 сохранены в манифесте. Официальные URLs Росстата записаны из существующего download plan. Если ссылка недоступна, локальная проверенная копия обеспечивает воспроизводимость.
